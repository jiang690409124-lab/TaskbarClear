# TaskbarClear

把 Windows 10 任务栏变全透明的极简小工具：托盘常驻，一键透明，一键恢复。

## 用法

- 双击 `TaskbarClear.exe`：任务栏立即变全透明
- 左键单击托盘图标：透明 / 恢复系统默认 来回切换
- 右键托盘图标：任务栏透明（当前状态带勾选）、恢复系统默认、透明度…、退出
- 右键「透明度…」：小窗滑块 0-100%，拖动实时生效；0% = 完全不透明，100% = 完全透明且清晰无模糊
- 退出时自动恢复系统默认外观；explorer 重启后会自动恢复透明状态

## 不包含

开机自启、记住上次状态、动态规则、自定义颜色、快捷键（以后要加都是小增量）。

## 构建

需要 MSYS2 UCRT64 的 g++ 与 windres（默认路径 `D:\C++\MSYS2\ucrt64\bin`，可用环境变量 `MSYS2_BIN` 指定）。

```bash
./build.sh        # 生成 build/TaskbarClear.exe
./build.sh test   # 运行核心逻辑自测
./build.sh probe  # 生成任务栏透明度探针（运行后透明 3 秒再恢复）
```

Windows 命令行：`build.bat [all|test|probe]`

注意：Git Bash 下必须让 MSYS2 UCRT64 的 bin 排在 `/mingw64/bin` 前面，否则 cc1plus 会加载错版本 DLL 并静默失败；`build.sh` 已自动处理。

## 实测数据（2026-11-24，Win10 19045 x64）

| 项目 | 目标 | 实测 |
|---|---|---|
| exe 大小 | ≤ 200 KB | 32768 字节（约 32 KB） |
| 私有工作集（任务管理器「内存」列） | ≤ 5 MB | 1085440 字节（约 1.04 MB） |
| 私有提交 | 记录值 | 1536000 字节（约 1.46 MB） |
| 总工作集（含共享 DLL 页） | 记录值 | 7639040 字节（约 7.3 MB） |
| 空闲句柄数 | 稳定 | 124 |
| 50 次切换后句柄数 | 与空闲差值 ≤ 5 | 124（差值 0，内存数值也完全不变） |
| explorer 重启自动恢复 | 通过 | 通过（重启后与透明基线差 2.8，与默认基线差 43.55） |
| 透明/恢复/退出像素对比（任务栏矩形内） | 明显变化 / 完全恢复 | 透明 vs 默认 71.32；命令恢复后 0；退出后 0 |
| 清晰度（条纹背景对比度） | 100% 应与背景一致不发糊 | 100%：25.8（清晰）；50%：15.6（半透明仍清晰）；25%：11；0%：6.7（不透明）；旧的模糊方案：18.1 |
| 透明度滑块 | 0-100% 实时生效 | 通过（0% 实心、50% 半透明、100% 全透） |
| 单实例 | 重复启动只有 1 个进程 | 通过 |

说明：Win10 19045 实测，`ACCENT_ENABLE_TRANSPARENTGRADIENT + AccentFlags=2 + alpha=0` 才是**清晰全透明**；`AccentFlags=0 + alpha=0` 会退回磨砂模糊，`BLURBEHIND/ACRYLIC` 也都会模糊。半透明档位用深灰 tint，alpha 越大越不透明。

## 已知限制

- 只保证 Windows 10 x64（10.0.19045 实测）；Win11 未验证
- 使用未公开接口 `SetWindowCompositionAttribute`，Windows 大版本更新后可能失效
- 全屏独占游戏、远程桌面下效果可能被系统接管
- 与 TranslucentTB 等同类工具同时运行可能互相覆盖
- 强制结束进程（任务管理器结束任务）不会触发恢复逻辑，任务栏会保持透明直到重启 explorer；请用托盘菜单「退出」正常关闭
