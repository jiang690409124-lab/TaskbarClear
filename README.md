# TaskbarClear

把 Windows 10 任务栏变全透明的极简小工具：托盘常驻，一键透明，一键恢复。

## 用法

- 双击 `TaskbarClear.exe`：任务栏按当前透明度生效（默认 100% 完全透明）
- 左键单击托盘图标：在「系统默认外观 / 上次透明度」之间快速切换
- 右键托盘图标：只有「任务栏透明度」和「退出」两项
- 点「任务栏透明度」：小窗滑块 0-100%，拖动实时生效；0% = 系统默认外观，100% = 完全透明且清晰无模糊
- 退出时自动恢复系统默认外观；explorer 重启后会自动恢复透明状态
- 开始菜单/搜索等系统界面打开期间，任务栏会跟随系统默认外观（Windows 自身行为，无法覆盖）；关闭后 0.5 秒内自动恢复设定透明度

## 不包含

开机自启、记住上次状态、动态规则、自定义颜色、快捷键（以后要加都是小增量）。

## 构建

需要 MSYS2 UCRT64 的 g++ 与 windres（默认路径 `D:\C++\MSYS2\ucrt64\bin`，可用环境变量 `MSYS2_BIN` 指定）。

```bash
./build.sh        # 生成 build/TaskbarClear.exe
./build.sh test   # 运行核心逻辑自测
./build.sh probe  # 生成任务栏透明度探针（运行后透明 3 秒再恢复）
```

Windows 命令行：`build.bat [all|test|probe]`

注意：Git Bash 下必须让 MSYS2 UCRT64 的 bin 排在 `/mingw64/bin` 前面，否则 cc1plus 会加载错版本 DLL 并静默失败；`build.sh` 已自动处理。

| 打开设置窗口后内存（注） | 记录值 | 私有工作集约 25.1 MB、私有提交约 35.5 MB；本机搜狗输入法等注入可见窗口所致（空白窗口最小复现同样现象），非本进程泄漏；关闭窗口后不回落 |

| 清晰度（条纹背景对比度） | 100% 清晰不发糊；0% 与系统默认一致 | 100%：27.9（清晰）；50%：15.2（半透明仍清晰）；0%：4.8（与退出后默认差 2.41）；旧的模糊方案：18.1 |
| 托盘菜单 | 只剩「任务栏透明度」「退出」 | 通过（截图验证） |
| 开始菜单打开/关闭 | 关闭后自动恢复 | 打开时对比度 5.3（系统强制接管）；关闭后 28.0（0.5 秒内自动恢复） |
| 单实例 | 重复启动只有 1 个进程 | 通过 |

说明：Win10 19045 实测，`ACCENT_ENABLE_TRANSPARENTGRADIENT + AccentFlags=2 + alpha=0` 才是**清晰全透明**；`AccentFlags=0 + alpha=0` 会退回磨砂模糊，`BLURBEHIND/ACRYLIC` 也都会模糊。半透明档位用深灰 tint，alpha 越大越不透明；0% 不走 tint 路径，直接恢复系统默认外观。

关于内存：空闲（仅托盘）私有工作集约 1.04 MB。打开设置窗口后数值上升，是本机搜狗输入法/美化组件注入所有可见窗口造成的——用空白窗口程序最小复现，同样约 35 MB 私有提交、数百句柄；切换透明度 40 次句柄与内存均不增长，属系统环境行为，不是本程序泄漏。

## 已知限制

- 只保证 Windows 10 x64（10.0.19045 实测）；Win11 未验证
- 使用未公开接口 `SetWindowCompositionAttribute`，Windows 大版本更新后可能失效
- 全屏独占游戏、远程桌面下效果可能被系统接管
- 与 TranslucentTB 等同类工具同时运行可能互相覆盖
- 强制结束进程（任务管理器结束任务）不会触发恢复逻辑，任务栏会保持透明直到重启 explorer；请用托盘菜单「退出」正常关闭
